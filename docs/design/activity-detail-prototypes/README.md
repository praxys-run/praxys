# 活动详情 · 已选 A 版与设计探索对照

这是**独立的静态原型**。A「跑后报告」已选为下一步方向，并提供 Praxys Field Lab 品牌版；B/C 和原版 A 保留供对照。这里不是已上线的活动页面，也不会读取账户或真实训练记录。设计决策、行为与数据前提见 `docs/design/activity-detail-experience-spec.md`。

| 方向 | 从哪里开始 | 适合 | 需要权衡 |
| --- | --- | --- | --- |
| A 跑后报告 | 全程概况 → 主图叠加 → 分段对照表 → 其余记录 | 快速回想一次跑步，并按列比较每段 | 多条曲线分轨细看不如 B 直接 |
| B 数据工作台 | 双曲线叠加 → 独立分轨 → 来源记录 | 交叉检查功率、心率、配速 | 初始信息较密，需要谨慎控制默认量 |
| C 分段节奏簿 | 选择分段依据 → 局部叠加曲线 → 全程索引 | 按设备圈或公里复盘 | 无分段时只能退化为全程汇总 |

在仓库根目录运行：

```sh
python3 -m http.server 8781 --bind 127.0.0.1 --directory docs/design/activity-detail-prototypes
```

浏览器打开 `http://127.0.0.1:8781/` 对照三版；`?v=report` 是选定的 A × Field Lab 品牌版，可在页面顶部切回**原 A 视觉**（直达 `?v=report&skin=original`），切换不会重置已选曲线／分段。`?v=report&theme=dark` 预览品牌深色；`?v=console`、`?v=chapters` 保留原貌。右上角可切换“多指标活动”“采样不完整”“只有汇总”。桌面页面和窄屏页面使用同一数据模型，手机布局仅模拟小程序的使用情境，不是实际小程序。品牌字体现依照 `docs/brand/index.html` 从 Google Fonts 加载，离线仍可用系统字形回退；正式 Web 的全站字体迁移不在本原型里。

**新版 A 的分段对照**：`?v=report` 默认用可扫描的表格排齐分段、距离、用时、配速及来源设备圈已有的功率／心率均值；点击任一行定位到上方同一时间轴，并在图旁保留所选段的距离、用时与配速，可返回原行。手机保留表格语义，将来源圈的额外均值并入行内次要文字，避免横向滚动。按“原卡片”可直接对照先前设计；`?v=report&layout=cards` 也可直达旧卡片布局。切换展示方式不会重置已选曲线或段落。

**A 的 Impeccable 改进**：手机上压缩仅属于设计实验的导航和重复标题，使主图在首屏即可开始阅读；首屏以来源分圈的首、末配速作为可核对的记录观察，不提供 AI 评价或训练建议。叠加曲线的实时读数只在图例显示一次，时间由游标控件显示；双纵轴说明、采样来源与缺口提示移到图下，不挡住曲线。记录区的展开入口直接写明已存项目数；只有汇总的样本跳过空白曲线框和不可用的分段控件，提供可打开全部记录的直达入口。RSS、CP 估计只显示 Stryd 给出的整场汇总，并在记录旁解释用途，不将它们伪装成逐时采样。

2026-09-28 复核：A 的五项优先反馈中，分段表格与选段上下文已保留，本轮处理了首屏曲线、重复读数及偏小单位、折叠记录入口和 RSS／CP 释义。390×844 手机主图顶部从修改前约 977px 提前到约 576px；320×700 与 1440×900 均无横向溢出。Impeccable 浏览器检测在 A 版仅提示 1 项纸张配色审美偏好，此处保留选定的视觉方向；静态检测对含 A/B/C 的整个原型目录有 321 项设计系统偏离提示，不能等同于 321 个 A 页面缺陷。这是 `polish` 后的检测和人工验收，不是一次新的独立双评审评分；原有 23/40 仍是旧版基线。

可选主曲线、叠加一条真实存在于该示例中的采样曲线，或关闭叠加；默认用功率与心率演示。两条线共享时间轴但使用各自的纵轴、颜色与线型，图例和时间游标同时显示各自的单位；配速越小越快，因此配速线向上表示提速。**上下位置只能比较变化趋势，不能把不同单位的数值大小直接相比。**在曲线上拖选区间、点击分段或使用缩放按钮可以放大。曲线获得焦点后可用左右方向键、Home/End 移动；C 的全程索引可点击或用方向键切换分段。仅有活动汇总值的记录不绘制假曲线；采样缺口不跨越补线；只有一条采样曲线时，叠加入口解释为何不可用。

A 版的时刻游标由图中竖线和图下同宽的滑杆共同定位：悬停／点击曲线或拖动滑杆可同步查看该时刻所选曲线已有的读数，缺测处不补值。游标本身不放大；拖选区间或点「放大」才改变可见范围，点「全程」还原。桌面版将缩放操作放在图卡右上，不再占用游标的宽度；窄屏将按钮排在曲线下，保留可点击尺寸。

这里的「分段」有两种明确不同的来源：**设备圈**与**每公里**。设备圈是合成示例的四个 3.1 km 圈（稀疏示例为三个圈），标题仅为原型章节；无法从当前保存的来源分圈判断它是自动圈还是手动按圈，界面不作猜测。「每公里」只在多指标示例中可选，使用独立生成的逐时合成距离轨迹按 1 km 切开，末段保留 0.4 km；距离轨迹完整，而功率、心率等仍有各自的采样缺口。公里段不是另一个来源圈，也不是仅凭活动平均配速伪造的每公里结果。稀疏示例缺少逐时距离，只有汇总示例连逐时曲线和分段都没有，两者都不会生成每公里记录。正式实现前需核对数据接口能否提供分圈类型、连续距离、缺口与活动时钟语义。

公里段对照表只列依据合成距离轨迹获得的距离、用时与配速；虽然原型中有来源圈均值，**不会把它们插值后冒充每公里的功率／心率汇总**。仍可在上方同一时轴查看存在的功率与心率采样曲线。正式实现应分别核实“来源设备圈”和“按距离切分”的数据来源及可用字段。

所有日期、运动数值、曲线、来源名称都是**合成演示数据**，不是运动分析结论；不包含 GPS 地图、AI 评价或训练建议。A 的品牌版使用暖纸／平整图卡、Geist 与 JetBrains Mono、行动绿与解释蓝的分工；功率／心率／配速曲线另有具名观测色，不把“跑得更快”染成建议。原版 A 的 Impeccable 独立体验／浏览器检测评审快照保存在 `.impeccable/critique/`，供选版时对照；其 23/40 记录的是改表格**之前**的体验，不能视为本版评分。原型不改正式 Web／小程序页面，也不接 API、数据库。本地验收截图保留在 gitignored 的 `test-screenshots/ui-quality/activity-detail-prototypes/`。
